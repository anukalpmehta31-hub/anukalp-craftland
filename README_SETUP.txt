ANUKALP CRAFTLAND — FIREBASE ANDROID PROJECT

1. Open this folder in Android Studio.
2. In Firebase Console download google-services.json for package:
   com.anukalp.craftland
3. Put it at:
   app/google-services.json
4. Firebase Authentication: Email/Password enabled and owner:
   anukalpmehta31@gmail.com
5. Firestore rules: use the rules you already published.
6. Sync Gradle and Run.

This starter has owner login, owner-only add Map/Asset, public read, and Firestore storage.
Password/OTP is never included in the project.
